## 1. Formato do relatório

- [x] 1.1 Substituir a orientação genérica de consolidação por um template final
  de relatório em Markdown.
- [x] 1.2 Definir o formato e os campos esperados para resumo, escopo,
  arquitetura, dependências, fluxos e integrações técnicas.
- [x] 1.3 Padronizar a apresentação de evidências, confiança, fatos, inferências,
  lacunas e perguntas em aberto.
- [x] 1.4 Instruir o tratamento de seções sem achados e a referência obrigatória
  ao codebase ou à configuração disponível.

## 2. Validação

- [x] 2.1 Verificar que o template abrange todas as capacidades já investigadas
  pelo roteiro.
- [x] 2.2 Verificar que todo item relatado tem formato Markdown e permite
  distinguir evidência de conclusão não comprovada.
